# Find-the-donor-app

Red Line Blood Donation Mobile App (React Native + Expo + TypeScript + Supabase), built from [RED-line-update](https://github.com/Kiruthikeyan-S/RED-line-update).

## Setup

1. Run `supabase/schema.sql` in your Supabase Dashboard SQL Editor.
2. Copy `.env.example` to `.env` and fill in `EXPO_PUBLIC_SUPABASE_URL` and `EXPO_PUBLIC_SUPABASE_ANON_KEY`.
3. Install dependencies and start Expo:
   ```bash
   npm install
   npx expo start
   ```
